# 나의 마음 지킴이 v1

Google Stitch 원본 UI 기반의 특수학급 자기조절 웹앱입니다. 13개 화면, 별도 서버나 회원가입이 필요 없는 정적 웹앱입니다.

## 실행 방법
1. ZIP 압축을 풀어 모든 파일을 한 폴더에 보관합니다.
2. Windows에서 Python 3이 설치되어 있다면 `start-windows.bat`를 실행합니다. 또는 폴더에서 `python -m http.server 8765 --bind 127.0.0.1`를 실행합니다.
3. Chrome에서 http://127.0.0.1:8765/index.html 을 엽니다. 이 주소는 해당 컴퓨터에서만 접근할 수 있습니다.
4. 태블릿에서는 정적 웹 호스팅(예: Cloudflare Pages Direct Upload)에 압축을 푼 프로젝트 전체를 업로드합니다. 빌드 명령은 필요 없으며 index.html이 루트에 있어야 합니다. 발급된 HTTPS 주소를 태블릿 Chrome에서 엽니다. 메뉴의 홈 화면 추가/앱 설치를 이용할 수 있습니다. 최초 온라인 접속 후 오프라인 작동 여부를 확인하세요.

## 교사용 설정
- 처음 교사용 설정에 들어가면 PIN을 설정합니다. 기본 프로필은 '친구 1'입니다. 학생은 별칭으로 등록하고 교사가 사용할 프로필을 선택합니다.
- 심호흡 기본값은 들이마시기 3초, 내쉬기 4초, 3회입니다. 음성 속도, 휴식 시간, 표시할 카드 등을 변경할 수 있습니다.
- 활동 기록은 기본적으로 꺼져 있습니다. 필요할 때 프로필별로 켜고 CSV로 내보낼 수 있습니다. 실제 이름이나 민감한 정보는 입력하지 않는 것이 좋습니다.
- 기록과 설정은 해당 브라우저의 로컬 저장소에 보관됩니다. 브라우저 데이터 삭제 시 사라질 수 있습니다. PIN은 교실 내 설정 변경을 제한하는 간단한 잠금이지 강력한 인증 수단은 아닙니다.
- 도움 요청은 화면과 음성으로 전달합니다. 교사의 다른 기기로 알림을 보내거나 보호자에게 정보를 공유하지 않습니다.

## 개발 및 검증 범위
원본 Stitch HTML과 색상, 그림, 배치를 재사용했습니다. 외부 이미지 접근 제한으로 원본 화면 이미지에서 캐릭터를 추출하여 로컬화했습니다. 일부 글꼴/아이콘은 대체 표시되며 태블릿에서 잘리는 부분을 조정했습니다. 원본 교사용 예시 데이터는 실제 로컬 기록 화면으로 교체했습니다.
컴퓨터 Chromium의 화면 렌더링 및 기능 테스트를 수행했습니다. 환경 제한으로 화면 이동·저장·TTS는 테스트용 대체 환경에서 검사했습니다. 실제 태블릿의 한국어 음성, HTTPS 호스팅, PWA 설치와 서비스워커 오프라인 동작은 별도 확인이 필요합니다. 이 파일은 아직 인터넷에 배포되지 않았습니다.
